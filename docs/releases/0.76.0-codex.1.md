# 0.76.0-codex.1

Core 0.76.0 을 싣습니다. 답 모양이 바뀝니다 — 다시 쓴 요청 인용이 답 첫 줄에 오고, 그 아래는 굵은 주제와 두괄식 개조식 불릿('~함 · ~임')입니다. '이렇게 이해하고 일함' 줄은 없어졌습니다.

- 답 검사: 목록 · 표로 시작해도 되고, 긴 줄글 문단 · '~습니다' 불릿 · 맨 위가 아닌 다시 쓴 요청을 잡습니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
