# SCV for Codex 0.20.4-codex.2

이 patch release는 Claude Code와 Codex의 project state 판별을 SCV Core
`v0.20.6`의 단일 구현으로 통합합니다.

## 사용자 동작

- `scv/CLAUDE.md`, `scv/CODEX.md`, `scv/SCV.md`의 상태 조합을 두 host가
  같은 return code와 hydration 의미로 판별합니다.
- 기존 readable state와 `scv/INTAKE.md`가 있으면 conflict 중에도 hydrated
  project로 진단합니다. 단, conflict를 자동 선택하거나 덮어쓰지 않으며
  mutating sync는 rc 4로 중단합니다.
- Claude에서 migration한 뒤 Codex로 전환하거나 그 반대로 전환해도 exact
  HTML pointer marker를 통해 같은 canonical `scv/SCV.md`를 읽습니다.
- canonical target이 없는 pointer는 양쪽 모두 broken pointer로 거부합니다.

## 구현 경계

- state inspection, migration preview, backup, canonical seed, pointer
  finalization은 Core가 소유합니다.
- Codex adapter의 `state-index.sh`는 pinned Core entrypoint에 argv와 검증된
  host profile만 전달합니다.
- canonical seed는 no-replace이며, pointer를 게시하기 전에 모든 active
  legacy 파일을 backup과 다시 비교합니다.

## 호출 방식

Codex에서는 자연어 요청이 기본입니다. 정확한 skill 선택이 필요할 때만
`$scv:<action>`을 사용할 수 있습니다. `/scv:<action>`은 Claude Code의 slash
command이며 Codex 호출 문법이 아닙니다.
