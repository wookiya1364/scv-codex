# 0.48.0-codex.1

Core 0.48.0 동기화. Codex 래퍼 자체의 동작 변경은 없습니다.

## 코어에 들어온 것

- **help 매 턴 비용 다이어트.** help 규약 본문이 28KB 에서 13KB 로 줄고, 분기 전용 본문 다섯이
  `protocols/help/*.md` 부속 파일로 갔습니다. Codex 스킬은 `vendor/scv-core/core/protocols/help.md`
  를 읽으므로 부속 파일도 같은 벤더 트리에서 `$SCV_CORE_ROOT/protocols/help/<name>.md` 로
  풀립니다. `help.sh --with-context` 는 파싱 머리만 찍고, archive 목록은 `--archive-index` 로만.
- **run-dry 앵커 정리.** 코칭 문구만 고정하던 32개와 중복 3개 삭제, 남는 문장 고정에 `# why:`,
  새 검사 `test-anchor-intent.sh`.

## 확인한 것

- 벤더 트리의 `protocols/help/` 다섯 파일에 자리표시자 리터럴이 남지 않습니다(재료화 검사).
