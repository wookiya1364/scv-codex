# 0.69.0-codex.1

Core 0.69.0 을 싣습니다. Core pin 은 `0.69.0`.

## 무엇이 달라지나

- **다음 일은 묻지 말고 계속**: 막힌 것도 사용자가 정할 것도 없으면, 배경 작업 알림 뒤나 한 단계가 끝난 뒤 '다음으로 무엇을 할까요?'
  질문으로 멈추지 않고 이어서 일합니다. 진짜 결정(사용자만 정할 수 있는 것 · 되돌리기 어려운 일)은 그대로 묻습니다.
- **드림 — 프롬프트 코치(`$scv:dreams`, 새 명령 · 16번째)**: 이 프로젝트의 지난 세션 기록과 보관된 계획을 읽기만 해서, 계획 하나를
  보관까지 끌고 가는 데 사람 요청이 몇 번 들었는지와 처음 요청을 어떻게 쓰면 더 적게 들지를 보고서로 냅니다(`scv/dreams/` 에만 씀).
  끄기: `SCV_DREAMS=off`.
- 알려진 한계: Codex 에는 세션 시작 훅이 없어 드림은 직접 부를 때와 날짜가 바뀐 첫 요청 때만 돌고(대화 비움 · 압축 직후는 아님),
  판정자를 싣지 않아 개선점 칸은 '조언 없음'으로 나옵니다(숫자 · 근거는 그대로).
