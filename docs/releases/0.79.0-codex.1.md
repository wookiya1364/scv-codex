# 0.79.0-codex.1

Core 0.79.0 을 싣습니다. `SCV_LANG` 을 korean 으로 둔 프로젝트에서 매 턴 맨 앞에 언어 규칙 한 줄을 싣고, 최종 답이 다른 언어로 흐르면 한 턴에 한 번 막아 그 줄만 고쳐 쓰게 합니다. 사용자가 그 턴에 다른 언어를 요청하면 강제하지 않습니다. 코덱스에는 도구 뒤 훅이 없어 턴 중간 교정은 적용되지 않습니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
