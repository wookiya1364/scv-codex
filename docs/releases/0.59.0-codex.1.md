# 0.59.0-codex.1

모델을 바꿔도 그 모델에 맞춘 프롬프트로 일합니다. Core pin 은 `0.59.1`.

## 무엇이 달라지나

- **help 가 지금 답하는 모델의 공식 프롬프팅 가이드 원문을 읽습니다.** OpenAI 는 모델마다 공식 가이드가 따로 있습니다(GPT-6 ·
  GPT-5.6 · Codex · GPT-5.2 · GPT-5.1 · GPT-5 + 공통 Prompt engineering). 플러그인이 그 원문을 오프라인 사본으로 싣고, 모델이
  바뀌거나 새 대화 뒤 처음이면 help 가 원문을 한 번 읽게 합니다. 인터넷 없이 됩니다.
- **요청을 그 가이드 기준으로 다시 써서 보여 준 뒤 그것으로 일합니다.** 가이드가 그 모델에 권하는 요소(목표 · 끝 조건 · 범위 ·
  멈출 조건 · 피할 것)를 대화 · 저장소 · 계획에서 먼저 찾아 채우고, 못 찾는 것 중 결과를 가장 크게 바꾸는 하나만 추천 답과 함께
  묻습니다(소크라테스식). 사용자의 원래 문장은 그대로 남습니다.
- 모델이 자기 모델 id 를 모르면 코덱스 설정의 `model` 줄에서 읽습니다(런타임 참조 문서에 한 절).
- 설정: `SCV_MODEL_PROMPTING`(on · 기본 / off), `SCV_MODEL_PROMPTING_MAX_AGE_DAYS`(90). 원문 갱신:
  `bash plugins/scv/prompting/refresh.sh`.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
