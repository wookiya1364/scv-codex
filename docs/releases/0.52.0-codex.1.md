# 0.52.0-codex.1

계획서가 바뀔 함수를 먼저 말하고, 기획서가 그것을 그림으로 보여줍니다. Core pin 은 `0.52.0`.

## 무엇이 달라지나

- **변경 지도.** 계획 폴더로 만든 기획서에 절 하나가 자동으로 붙습니다. 계획서의 `## 순수함수 · 파이프라인` 표에
  단계마다 상태(추가 · 변경 · 삭제 · 재사용)를 적으면, 그 파이프라인이 상태별 색으로 구분된 머메이드 그림 한 장과
  표 하나로 그려집니다. 삭제로 가는 선은 점선입니다. 상태 칸이 없는 옛 서식은 `미지정` 이 되고, 계획서가 삭제를
  말하지 않으면 삭제 행은 만들지 않습니다.
- **화면과 함수가 이어집니다.** 화면 설계의 번호가 파이프라인 단계를 가리키면 그 상태까지 함께 보입니다.
- **Graft 는 선택입니다.** 있으면 선언을 실제 코드와 대조해 `일치` · `이미 있음` · `근거없음` 으로 표시하고,
  없으면 설치 명령 한 줄만 안내합니다. 설치·초기화·빌드·훅은 하지 않습니다.
- **벽시계 단언 제거.** 시간을 재서 초록·붉음을 가르던 검사 단언을 전부 걷어냈습니다. 부하 한 번에 보관 계획
  25건이 함께 붉던 원인입니다. 걸린 시간은 출력에만 남습니다.
- **deck 안내문 중복 수정.**

## 올리는 법

codex plugin update scv
