# 0.68.0-codex.1

Core 0.68.0 을 싣습니다. Core pin 은 `0.68.0`.

## 무엇이 달라지나

- **실사용 보고 판정기**: 실사용 보고가 '실제 결과를 보이고 물었나'를 기록 구조로 셉니다(편집 → 실행 → 그 출력을 글에 그대로
  인용 → 끝 물음표 질문). 결과를 보인 뒤 물음표 없이 끝난 애매한 턴은 판정자(모델) 몫인데, Codex 래퍼는 판정자를 싣지 않아 그
  턴은 '판정 못 한 턴'으로 숫자만 셉니다(알려진 한계).
- 매 턴 안내 · 계약 문구 · 스위치는 그대로입니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
