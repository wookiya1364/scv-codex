# 0.66.0-codex.1

Core 0.66.0 을 싣습니다. Core pin 은 `0.66.0`.

## 무엇이 달라지나

- **처음 돌아가는 순간 실제 결과를 보여 주기**: 결과물이 바뀌는 일이면 모델이 가장 작은 것을 실제로 실행해 결과를 그대로
  보여 주고, '이대로 계속할까요, 고칠 점이 있나요?'를 글 질문 한 번으로 묻습니다. 결과물이 안 바뀌는 일은 묻지 않습니다. 효과는
  아직 증명되지 않아 실사용 보고로 확인합니다. 끄기: 설정 `SCV_SHOW_REAL=off`.
- **밀어붙여도 해로운 변경은 먼저 묻기**: 측정 · 실행으로 해롭다고 확인한 변경(결과 틀림 · 오류 숨김 · 2배 이상 느려짐)은
  밀어붙여도 그대로 넣지 않고, 넣기 전에 글 질문 한 번으로 묻습니다(추천 = 실제 원인 고치기). 추정뿐이거나 효과만 없는 변경은
  막지 않습니다. 원칙 스위치(`SCV_REWRITE_PRINCIPLE=off`)로 함께 꺼집니다.
- Codex 에는 고르는 선택지 도구도, 사람이 없는 실행을 가리는 조건도 없어 무인 실행에서도 두 안내 모두 글 질문 문구가 실립니다
  (알려진 한계).
