# 0.75.0-codex.1

Core 0.75.0 을 싣습니다. 계획을 구현하는 동안 단계가 바뀌면 호스트의 단계 기록 도구로 알리는 규칙(코어 'Step progress')이 들어왔습니다.

1. **단계 보고**: 호스트 설정에 단계 보고 도구가 있을 때만 동작합니다. Codex 에는 그 도구가 없어 이 래퍼에서는 아무 일도 일어나지 않습니다 — 매 턴 안내도 그대로입니다.
2. **순수함수 사전 형식 고정**: 사전 항목 모양(이름 · 역할 · 위치)을 코어 시험이 고정합니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
