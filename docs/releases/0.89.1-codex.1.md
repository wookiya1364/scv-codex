# 0.89.1-codex.1

Core 0.89.1 을 싣습니다(0.88.2 · 0.88.3 · 0.89.0 의 변경 포함).

**잘못된 거절 셋을 고쳤습니다.** 기록 폴더(`scv/raw` · `scv/journal` 따위)를 다른 저장소로 연결해 둔 프로젝트에서 기록 파일만 바꾼 턴이 막히던 것, 진행 메모가 계획의 '하지 않음' 항목과 낱말 하나만 같아도 거절되던 것(이제 항목 낱말의 절반 이상일 때만), 연결된 원자료 폴더를 옮기기가 거절하던 것.

**맥 기본 bash(3.2)에서 그래프가 죽던 것을 고쳤습니다.** 계획이 가리키는 파일이 없을 때 생기던 오류입니다.

Core 0.89.0 의 권장 effort 요청은 래퍼가 모델별 권장 표를 실어야 켜집니다. 이 래퍼는 아직 표를 싣지 않아 동작이 그대로입니다.
