# 0.92.3-codex.1

Core 0.92.3 을 싣습니다(0.92.2 의 변경 포함). 이 래퍼는 0.92.2 를 건너뛰었습니다 — 가져온 코어 시험을 러너 한 대에서 모두 돌릴 때 시간 시험 하나("선택 답 17개를 2초 안에")가 한도에 걸쳤습니다. 원인은 한도가 아니라 앞 시험이 남긴 배경 프로그램이었고, Core 0.92.3 의 시험 실행기가 그것을 끝냅니다.

**고친 것.**
- 일하는 도중에 말을 보내면 그 턴의 계획 기록이 0 으로 돌아가던 것. 이제 앞 턴이 끝나지 않았을 때 온 말은 같은 턴으로 이어집니다(요청 번호와 기록이 그대로 남고, 새 말은 요청 글 뒤에 붙습니다). 턴을 멈춘 뒤에 보낸 말도 이어지는 턴으로 보므로, 멈추기 전에 고친 파일도 턴 끝에 기록을 요구합니다.
- 계획에 기록을 남겼는데도 턴이 "계획 기록이 없다 · 진행 중 계획이 없다"로 막히던 것(Core 0.92.2). 기록 명령을 어떤 모양으로 돌려도 실제로 돌았으면 기록한 턴으로 봅니다.
- 파일을 붙여 보낸 요청의 경로가 계획 기록에 그대로 적히던 것(Core 0.92.2). 첨부 파일의 경로를 "[첨부]"로 바꿉니다.

**코어 쪽 정리.** 시험 실행기가 시험이 남긴 배경 프로그램을 끝냅니다. 가장 긴 시험을 네 파일로 나눴고, PR 검사의 맥 조각을 일곱으로 늘렸습니다.

이 판은 시험과 CI 로만 확인했습니다. 실제 세션에서 돌려 보는 확인은 하지 않았습니다.
