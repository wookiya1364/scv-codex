# 0.93.2-codex.1

Core 0.93.2 를 싣습니다.

**고친 것 — 재는 검사가 일부 함수를 견주지 않고 빼던 것.**
- 순수 함수를 고치면 고치기 전 코드와 시간을 견주는 검사가 돕니다. 이 검사가 다른 파일의 함수에 기대는 함수를 "답이 달라 뺌"으로 내고 견주지 않았습니다.
- 고치기 전 코드를 파일 하나만 꺼내 와서 옆 파일이 없었기 때문입니다. 이제 그 파일이 있는 폴더의 파일들을 함께 꺼냅니다.

**고친 것 — 단계 보고 도구를 불렀는데도 턴이 끝나지 않던 것.**
- 단계 보고 도구가 있는 호스트에서, 그 도구를 불렀는데도 턴 끝 검사가 턴을 막던 것을 고쳤습니다. 검사가 대화 기록에서 이번 턴의 호출을 직접 셉니다.
- 이 래퍼에는 단계 보고 도구가 없어서 달라지는 것이 없습니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
