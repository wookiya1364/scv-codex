# 0.28.0-codex.1

Core 0.28.0 을 싣고, 이 어댑터의 가드 등록을 완성합니다.

## 어댑터 액션들이 드디어 영수증을 발급합니다

이 호스트에는 skill 호출 이벤트가 없어서, 영수증의 유일한 출처는 "액션 스크립트
디렉터리를 부르는 셸 명령의 관찰"입니다. 그런데 훅이 벤더링된 `core/scripts` 한
곳만 감시했고, `$scv:update`·`$scv:set-models`·`$scv:sync`·hydrate 는
`adapter/scripts/` 로 돌아 **아무것도 발급하지 않았습니다**. Core 계약이 요구하는
것을 변수 구조상 지킬 수 없었던 것인데, Core 0.28.0 이 `SCV_GUARD_SCRIPTS` 에
콜론 목록을 가르치면서 닫혔습니다. 두 훅 항목이 두 디렉터리를 함께 감시합니다.

## 훅 두 항목의 환경이 대칭이 됩니다

한 번 갈라져서 — `gate-write` 만 `.codex/config.toml` 면제를 갖고 있었습니다 —
같은 패치가 editor 경로로는 허용되고 shell 경로로는 거부됐습니다.
`$scv:set-models` 3단계가 정확히 그 파일 편집입니다. 이제 두 항목이 같은 환경을
싣고, 등록 테스트가 동일성을 단언합니다.

## 낡은 템플릿은 다음 액션이 알아서 메웁니다

Core 0.28.0 의 자동 새로고침이 이 어댑터에도 그대로 옵니다. 자세한 이야기와 출시
전 적대 검증 4렌즈 33건은 Core 의 CHANGELOG 에 있습니다.
