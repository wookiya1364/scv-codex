# 0.46.0-codex.1

Core 0.46.0 동기화.

## 깊은 질문을 배경 조사로 넘기는 스위치가 생겼습니다 (기본 꺼짐)

코어에 `SCV_DELEGATE_EFFORT`(기본 `off`) 가 추가됐습니다. 켜면 매 턴 안내에 한 블록이 더
실려, 여러 파일을 읽거나 검증이 필요한 질문을 배경 조사 에이전트에 넘기고 결과 전문을
`scv/raw/` 파일로 남기게 합니다. 답은 그 턴에 세션 그대로 나갑니다.

Codex 래퍼에는 그 배경 조사 에이전트가 없습니다. 스위치를 켜도 블록만 실릴 뿐 아무 일도
일어나지 않으므로, 지금은 꺼 두시면 됩니다 — 기본값이 그렇습니다. 세션의 추론 설정은
어느 경우에도 SCV 가 바꾸지 않습니다.

- Core pin `0.45.0` → `0.46.0`.
