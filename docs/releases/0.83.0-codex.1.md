# 0.83.0-codex.1

Core 0.83.0 을 싣습니다. 종료 검사가 답을 막고 다시 쓰게 하던 것을 그만두고, 어긋난 점을 다음 턴 첫 안내(`[SCV 직전 답] …`)로 넘깁니다 — 다시 쓴 답이 인용 · 세 줄을 되풀이해 같은 답이 두 번 보이던 문제(실제 세션 186턴 중 78턴)를 없앱니다. 예전처럼 막으려면 설정에 `SCV_STOP_MODE=block`. 제목형 확인 범위(`**확인한 것**` 아래 목록)를 빠진 줄로 보던 오탐도 고쳤습니다. 압축 · 세션 시작마다 읽는 공통 가이드는 요구 항목 인용이 든 구역만 원문 그대로 뽑은 발췌본으로 바뀝니다(37,672B → 15,073B).
