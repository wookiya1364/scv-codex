# 0.78.0-codex.1

Core 0.78.0 을 싣습니다. 0.77.0 전체를 다시 훑어 서로 부딪히던 지시 21곳을 정리했고, 요청 등록을 프로젝트 밖에서 부르면 바로 알리며, 답 언어 검사는 중간 보고까지 봅니다. 코덱스 쪽 3곳도 고쳤습니다 — 언어 설정과 모델 정책을 `scv/scv_settings.json` 에서 읽고(옮기지 않은 프로젝트만 `.env`), help 답 첫머리는 모드에 맞춥니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
