# 0.50.0-codex.1

Core 0.50.0 동기화. Codex 래퍼 자체의 동작 변경은 없습니다.

## 코어에 들어온 것

- **규약 지문 메아리** (`SCV_HELP_ECHO`, 기본 on). 규약 전체를 읽은 턴에 `help-state.sh mark` 가 8자리 지문을
  만들어 표식과 `scv/journal/.help-nonce` 에 씁니다. 모델은 매 턴 대화 기록에 `protocol: <지문>` 한 줄을 적고,
  턴 종료 훅이 표식과 비교해 없거나 다르면 다음 턴에 규약 전체를 다시 싣습니다(경고 한 줄 + 재읽기).
- **답 모양 린트** (`SCV_ANSWER_LINT`, 기본 on). 턴 종료 훅이 직전 답의 골격만 봅니다(첫 문단 문장 수 · 결론
  없이 표 시작 · 첫 문단 코드값 · 결정표 추천 열). 벗어나면 다음 턴 경고 + 재읽기. 답을 막지 않습니다.
- **Codex 에서의 범위.** 둘 다 턴 종료 훅(`on-stop.sh` 템플릿)과 매 턴 훅에 의존합니다. Codex 에 등가 훅이
  등록돼 있지 않으면 지문 검사·린트는 돌지 않고, 규약 읽기는 0.49 와 같이 새 세션·N턴 주기로만 다시 실립니다.
  이 릴리스는 코어 핀을 맞추기 위한 것입니다.
- 훅이 쓰는 파일은 `scv/journal/` 아래 넷(`.help-state` · `.help-nonce` · `.help-warn` · `.help-drift`), 전부
  ignore 대상.
