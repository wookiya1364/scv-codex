# 0.106.0-codex.1

Core 0.106.0 을 싣습니다.

**두 일을 가르고 합치는 명령이 들어왔습니다(`plan-link.sh split` · `join`).** 진행 중인 계획이 있는데 목표가 다른 일이 오고 두 일이 같은 파일을 고치지 않으면, 하던 일을 분기(옆에 만드는 git worktree 폴더)로 보내 이어 가게 하고 새 일은 원본에서 할 수 있습니다. 가를 때 확인 명령의 결과를 적어 두고, 합친 뒤 다시 돌려 `이름: 값` 줄끼리 비교합니다. 달라진 값이 있으면 다시 하기 단계가 계획에 붙습니다.

**뒤에서 도는 에이전트가 없으면 지금처럼 멈춥니다.** 가른 일을 이어 가려면 뒤에서 도는 에이전트가 필요합니다. 이 호스트에서 그 길은 확인되지 않았고, 일 규약은 그런 경우 지금처럼 멈추고 돌아오게 합니다.

**긴 계획에서 기록이 빨라졌습니다.** 계획 글을 다시 쓰는 일(멈춤 · 재개 · 단계 넣기)이 글이 길어지면 줄 수의 제곱으로 느려지던 것을 고쳤습니다. 결과는 그대로입니다.

## 알아 둘 것

- 지금의 멈추고 돌아오기의 출력과 종료 코드는 그대로입니다.
- 가르기는 원본의 작업 파일 · 색인 · 가지를 건드리지 않고, 합치기는 커밋을 만들지 않습니다. 깃 저장소가 아니거나 깃이 2.38 보다 낮으면 가르지 않습니다.
- 확인은 시험과 CI 로 했습니다. 이 호스트의 실제 세션에서 돌려 보는 확인은 하지 않았습니다.
