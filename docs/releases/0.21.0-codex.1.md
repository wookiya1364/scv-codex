# SCV for Codex 0.21.0-codex.1

이 release는 공유 SCV Core를 `v0.21.0`으로 올립니다. 변경은 전부 Core
소유이며 Codex adapter seam과 14개 액션은 바뀌지 않습니다.

## 사용자 동작

- **raw 문서 라이프사이클**: `action:promote`가 사용한 raw 원본을
  `scv/raw/stale/`로 이동(내용 불변)하고, 어떤 계획(slug)들이 그 문서를
  사용했는지 `scv/readpath.json`의 `ref_docs`에 누적 기록합니다. 따라서
  `scv/raw/` 바로 아래 남은 파일은 아직 어떤 promote에도 쓰이지 않은
  **unused** 문서입니다.
- `action:status`가 unused/consumed 구분, 문서별 사용 slug, 그리고 소비
  시점 이후 코드가 바뀌어 내용이 낡았을 수 있는 문서
  (`OUTDATED-CANDIDATE`)를 보여줍니다. `action:help` 배너가 unused 개수를
  알립니다.
- **기획서 deck**: 아키텍처 mermaid 다이어그램이 라이트/다크 테마 모두에서
  선명하게 보이도록 보정 CSS와 init 팔레트가 정렬됐고, 로컬 headless
  Chrome이 있으면 다이어그램을 인라인 SVG로 구워 **오프라인에서도 완전한
  렌더**로 열립니다. Chrome이나 네트워크가 없으면 기존 CDN + 텍스트 폴백
  방식이 그대로 유지됩니다 (`--no-static` / `SCV_DECK_STATIC=0`로 옵트아웃).

## 주의

- 0.21.0 이전 래퍼의 `readpath.sh update`는 상태 파일을 `ref_docs` 없이
  다시 써서 provenance가 사라집니다. 같은 프로젝트를 Claude Code와 함께
  쓰는 팀은 두 래퍼를 함께 업데이트하세요.

## 검증

- Core 스위트 전부 green (ubuntu·macos): `test-readpath-lifecycle` 51,
  `test-deck-doc` 142, `test-deck-static-mermaid` 13, `run-dry` 800, 루트
  계약 테스트. `outdated` 휴리스틱의 BSD awk 호환 수정 포함.
