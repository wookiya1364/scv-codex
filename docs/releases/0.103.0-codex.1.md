# 0.103.0-codex.1

Core 0.102.0 과 0.103.0 을 싣습니다.

**기어를 시킨 턴이 가벼워집니다.** 저장해 둔 기어를 돌리라는 요청(`$scv:gear run <기어>`)은 가벼운 길로 갑니다. 도움말을 부르고 요청을 등록하고 긴 끝 보고를 쓰는 대신, 값만 확인하고 기어를 돌린 뒤 두세 줄로 답합니다. 기어를 말하기만 한 글이나 없는 기어 이름은 보통 턴입니다. 끄려면 `scv/scv_settings.json` 에 `"SCV_GEAR_TURN": "off"`.

**값이 필요한 기어는 값을 물어봅니다.** 인자나 입력값이 있는 기어를 값 없이 시키면 값을 하나씩 안내합니다. 기본값이 첫 보기이고, 요청에 이미 적은 값은 묻지 않습니다. 새 명령 `gear.sh ask <이름>` 이 정해야 할 값을 줄로 냅니다.

**서로 어긋나던 지시를 정리했습니다.** 열 곳입니다. 예: 진행 중 계획의 단계를 알리라는 안내는 그 계획을 다루는 턴으로 좁혔고, 앞에서 돌린 검사의 결과를 읽어 "통과"라고 적으면 알림이 뜨던 것을 풀었습니다.

**알아 둘 것.**
- 기어 실행기는 실행이 끝날 때마다 저널에 한 줄(기어 이름 · 인자 · 종료 코드)을 남깁니다.
- `scv/gears/INDEX.tsv` 의 기어 줄 셋째 칸이 그 기어 흐름에서 가장 센 표시(`pure` · `effect` · `outward` · `judge`)를 담습니다.
- 닫는 요약 도구의 질문을 거절하는 가드 규칙(S)과 그림 도구 알림은 그런 도구가 있는 호스트에서만 돕니다 — 이 호스트는 달라지는 것이 없습니다.
- 기어 턴의 가벼운 길은 시험과 다른 호스트에서의 실행으로 확인했습니다. 이 호스트의 실제 세션에서는 돌려 보지 않았습니다.
