# 0.84.0-codex.1

Core 0.84.0 을 싣습니다. 한국어 설정(`SCV_LANG=korean`)이면 help 가 다시 쓰기 전에 한국어판 STE 낱말 목록(ASD-STE100 규칙을 옮긴 R1–R15 · 허용 동사 · 금지 낱말 · 용어)을 세션마다 한 번 싣고, 다시 쓴 요청이 그 목록을 따릅니다 — 실제 요청 20개 가린 비교에서 다시 쓴 요청 15승 3패, 길이 269자 → 157자, 그 답 10승 8패. 끄려면 `SCV_REWRITE_STE=off`. 첫 행동 안내 · 마무리 상자 질문 규칙 문구도 실제 동작에 맞췄습니다.
