# 0.44.0-codex.1

Core 0.44.0 동기화.

## 답의 모양을 정했습니다

help 가 답할 때 쓰는 부분들을 정했습니다 — 결론, 예상 밖의 사실, 항목별 표(지금 ·
바꿀 것 · 규모), 큰 항목만 상세, 속도·비용 같은 가로지르는 얘기, 추천을 붙인 결정 표.

## 무엇이 달라지나

- **질문에 맞는 부분만 씁니다.** 짧은 맞장구에는 결론만. 백지 아이디어에는 결론과
  표("지금" 칸은 "없음"). 항목 여럿 점검에는 전부. 완성돼 보이려고 더하지 않습니다.
- **확인한 것과 짐작을 섞지 않습니다.** 직접 확인한 사실에는 표시가 붙습니다.
- **서로 독립인 결정은 추천을 붙여 한 표로 묻습니다.** 번호로 한 줄에 답할 수 있습니다.
- **사람의 말로 답합니다.** 규약 안의 이름은 답에 나오지 않고, 사용자가 쓴 말을
  그대로 씁니다.

- Core pin `0.43.0` → `0.44.0`.
