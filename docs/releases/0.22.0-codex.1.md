# SCV for Codex 0.22.0-codex.1

이 release는 공유 SCV Core를 `v0.22.0`(Template **2.0.0**, scv-simplification
epic)으로 올리고, 15번째 액션 `$scv:routine`을 등록합니다(액션 계약 14 → 15).

## 사용자 동작

- **BREAKING — 표준 문서 7종 폐기**: Template 2.0.0이
  INTAKE/DOMAIN/RALPH_PROMPT/AGENTS/ARCHITECTURE/DESIGN/TESTING을
  제거합니다. sync가 기존 프로젝트에서 해당 파일을 삭제합니다 — 버전
  게이트 1회성 마이그레이션으로, 2.x 미만 template 스탬프에만 실행되고
  심링크된 `scv/`는 건너뜁니다. 복구가 필요하면 git history에서
  가져오세요. hydration 기준 파일은 `scv/INTAKE.md`에서 `scv/PROMOTE.md`로
  이동했습니다.
- **guardrails-first PLAN 문법**: 계획서가 바꾸지 않을 것(guardrails)을
  먼저 선언한 뒤 변경을 서술합니다.
- **작성자별 팀 저널 + DECISIONS/TODO**: 자유 대화가 커밋되는
  `scv/journal/<YYYYMMDD>-<author>.md`로 축적되고 DECISIONS.md/TODO.md가
  표준 문서로 합류합니다. 내장 redaction이 비밀값을 `[REDACTED]`로
  기록하며 원문은 디스크에 남지 않습니다.
- **NEW `$scv:routine` (15번째 액션)**: 루틴 카탈로그(`--list`)·lint·실행
  프로토콜이 이번 release에 등록됩니다. 스케줄 등록은 호스트 소유로
  유지됩니다 — 래퍼에는 crontab/systemctl/launchctl 등록 코드가 없고 안내
  텍스트만 전달합니다.
- **SCV:GUIDANCE 마커 + `SCV_GUIDANCE=minimal`**: 프로토콜 출력이 guidance
  마커로 감싸이고, minimal 모드로 안내를 줄일 수 있습니다.
- **훅 seam**: 훅 자동 등록은 Codex plugin 표면 한계로 문서화까지입니다
  (`references/journal-hooks.md` — 이벤트 매핑, stdin JSON 계약,
  `SCV_CORE_ROOT`, non-blocking·redaction 보장).

## 주의

- 같은 프로젝트를 Claude Code와 함께 쓰는 팀은 두 래퍼를 함께

  기준(`scv/INTAKE.md`)을 여전히 기대합니다.
