# 0.52.1-codex.1

Graft 를 처음 실제로 설치해 보고 잡은 결함 셋. Core pin 은 `0.52.1`.

## 무엇이 달라지나

- **코드 대조가 실제로 동작합니다.** Graft 의 응답 모양을 추정으로 감싸 두었는데 실물과 달라, 코드 후보가 한
  건도 잡히지 않았습니다 — 오류 없이 조용히. 이제 실물 모양을 먼저 읽습니다.
- **변경 지도가 그래프를 저장소 뿌리에서 찾습니다.** 계획 폴더에서 찾아 설치돼 있어도 없는 것으로 떨어졌습니다.
- **검사가 "Graft 없음" 을 가정하지 않고 만듭니다.** 전역 설치본을 놓치던 방식을 고쳤습니다.
- 실물 Graft 가 있을 때만 도는 검사 넷을 더했습니다.

## 올리는 법

```
codex plugin update scv
```
