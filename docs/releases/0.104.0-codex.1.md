# 0.104.0-codex.1

Core 0.104.0 을 싣습니다.

**오래 도는 일은 뒤에서 돕니다.** 오래 걸리는 일을 앞에서 기다리는 동안 새 메시지를 보내면 하던 일이 끊겼습니다. 이제 30초 이상 잠자거나 끝날 때까지 도는 기다림 셸 명령은 실행 전에 거절되고, 그 일을 뒤에서 돌리라는 안내가 나갑니다. 끄기: 프로젝트 설정 `SCV_BACKGROUND_FIRST=off`.

**단계의 증거는 눈에 보이는 것입니다.** 계획의 단계를 끝낼 때 내는 증거는 그림 · 영상 · 열어 볼 페이지이고, 소스코드나 글 파일은 증거가 아닙니다. 숫자뿐인 결과도 그림으로 낼 수 있게 막대 그림을 만드는 명령(`evidence-card.sh card`)이 생겼습니다.

**같은 일의 반복을 알아챕니다.** 요청이 이미 있는 기어와 겹치면 그 기어로 하라는 한 줄이, 전에 한 요청과 비슷하면 일을 마친 뒤 기어로 만들지 묻게 하는 한 줄이 그 턴에만 붙습니다. 겹치지 않는 턴에는 아무것도 붙지 않습니다. 요청은 비밀 가림 뒤 프로젝트의 기록 폴더에만 쌓이고 커밋되지 않습니다. 끄기: `SCV_GEAR_DETECT=off`.

**원칙 글이 매 턴 실리지 않습니다.** 규칙 글처럼 대화마다 한 번만 전문을 싣고, 대화가 요약 · 재개된 뒤와 경고가 남은 턴에만 다시 싣습니다.

**`$scv:dreams` 를 걷어냈습니다.** 지난 세션을 돌아보는 코칭 보고서 기능입니다. 명령 · 스킬 · 하루 한 번 뒤에서 돌던 실행이 없어졌고, 명령은 22개가 됐습니다. 이미 만들어진 `scv/dreams` 폴더는 건드리지 않습니다 — 필요 없으면 지우면 됩니다.

## 알아 둘 것

- 기다림 거절은 이 호스트에서 셸 명령의 잠자기에만 걸립니다. 대기 값을 받는 도구는 이 호스트의 훅이 보는 범위 밖입니다.
- 확인한 것: 등록된 환경 그대로 가드를 불러 120초 잠자기와 기다림 루프는 거절, 2초 잠자기는 통과, 끈 설정에서는 통과.
- 확인하지 못한 것: 실제 세션에서 훅이 받는 셸 명령이 글이 아니라 목록 꼴이면 이 거절이 걸리지 않습니다. 거절 글의 "끝나면 알림이 온다"가 이 호스트에서 그대로 맞는지도 보지 못했습니다.
- 실제 세션에서 돌려 보는 확인은 하지 않았습니다(시험과 CI 로만 확인).
