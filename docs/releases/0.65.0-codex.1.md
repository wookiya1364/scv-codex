# 0.65.0-codex.1

Core 0.65.0 을 싣습니다. Core pin 은 `0.65.0`.

## 무엇이 달라지나

- **세션마다 따로**: 이번 턴 상태(표 · 등록 · 막기 기록 · 경고)를 세션마다 둡니다 — 한 저장소에서 여러 세션을 써도 섞이지 않고,
  사람 메시지를 받지 않은 세션은 검사 · 저널 기록을 하지 않습니다. 세션 id 를 주지 않는 실행은 이 버전 전과 같습니다.
- **'변경 없음' 범위는 편집을 막음**: 등록의 범위 칸을 '변경 없음 — …' 으로 시작한 턴에는 프로젝트 파일 편집이 거절됩니다.
- **답의 모양**: 답 맨 위에 '이렇게 이해하고 일함: …' 한 줄, 결론 바로 뒤에 다시 쓴 요청 전문.
- 64KB 를 넘는 긴 답의 가운데 문제 표도 판정합니다.
- Codex 에는 고르는 선택지 도구가 없어 '선택 창 답 뒤 다시 등록'은 해당 없고, Codex 세션 기록은 모양이 달라 가이드 다시 읽기는
  이 버전 전의 판단 그대로입니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
