# 0.49.1-codex.1

Core 0.49.1 동기화. Codex 래퍼 자체의 동작 변경은 없습니다.

## 코어에 들어온 것

- **들여쓴 동적 펜스 변환 수정.** Claude 프로필 변환이 열 0 의 `!` 펜스만 `bash` 예시로 바꿔, 목록 항목 안에
  들여쓴 펜스 8곳이 그대로 남아 Claude Code 에서 스킬을 펼치는 순간 실행됐습니다. help 에서는 "규약을 읽었다"
  표식이 먼저 서서 0.49.0 의 규약 전체 읽기 분기가 뜨지 않았습니다. 변환이 앞 공백을 허용하고, 코어 검사가
  들여쓴 펜스가 남으면 실패합니다.
- **Codex 에는 영향이 없습니다.** Codex 프로필(argv-array)은 이 변환을 거치지 않고, Codex 는 `!` 펜스를
  실행하지 않습니다. 이 릴리스는 코어 핀을 맞추기 위한 것입니다.
