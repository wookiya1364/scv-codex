# 0.105.0-codex.1

Core 0.105.0 을 싣습니다.

**듣기 싫은 말을 다른 말로 바꿔 씁니다 — 새 명령 `$scv:words`.** 읽고 싶지 않은 말과 그 대신 쓸 말을 프로젝트의 낱말 사전(`scv/words/WORDS.tsv`)에 둡니다. 한 줄에 피할 말 · 쓸 말 · 다른 꼴들 · 메모입니다. 대화 첫머리에 사전이 한 번 실리고, 답에 피할 말이 나오면 다음 턴에 `[SCV 낱말]` 한 줄로 알립니다. 이미 보인 답은 다시 쓰게 하지 않습니다. `$scv:words` 로 목록을 보고, `add` · `remove` · `fill`(빈 꼴 채우기)을 붙이거나 "A 대신 B 라고 해"처럼 말로 해도 됩니다. 끄기: 프로젝트 설정 `SCV_WORDS=off`. 명령은 23개가 됐습니다.

**기록 색인 거르기가 빨라졌습니다.** 줄 수의 제곱으로 느려지던 것을 한 번만 훑도록 고쳤습니다(282줄에서 274초 넘게 → 0.04초).

## 알아 둘 것

- Core 0.105.0 의 "대화를 비운 뒤에는 기록의 끝부분만 싣기"는 세션 시작 훅의 일입니다. 이 호스트에는 그 훅을 등록하지 않아 이 판에서 달라지는 것이 없습니다.
- 낱말 사전은 사람이 읽는 글(답 · 진행 알림 · 요약)에만 걸립니다. 코드 · 파일 이름 · 명령 · 사람의 말을 옮긴 글에는 걸리지 않습니다.
- 확인은 시험과 CI 로 했습니다. 실제 세션에서 사전을 넣고 여러 턴을 돌려 보는 확인은 하지 않았습니다.
