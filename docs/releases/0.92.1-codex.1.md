# 0.92.1-codex.1

Core 0.92.1 을 싣습니다(0.89.2 · 0.90.0 · 0.91.0 · 0.91.1 · 0.91.2 · 0.92.0 의 변경 포함). 이 래퍼는 0.92.0 을 건너뛰었습니다 — 가져온 코어 시험을 여럿 함께 돌릴 때 시간을 재는 시험이 실패했고, 0.92.1 이 그 시험에 "혼자 돈다" 표시를 붙였습니다.

**재는 명령(새 기능).** 순수함수 하나(또는 셸에서 띄우는 명령 하나)의 시간 · 메모리 · GPU · 다른 프로그램을 부른 횟수와, 입력을 4배로 늘렸을 때 시간이 몇 배가 되는지를 잽니다. 순수함수 사전이 있는 프로젝트에서 사전에 오른 함수를 고치면, 턴이 끝날 때 고치기 전 코드와 견줍니다(최대 35초). 한도를 넘으면 멈추고 실제 숫자로 묻습니다. 사전이 없는 프로젝트에서는 아무것도 재지 않고, 설정 `SCV_PURE_BENCH=off` 로 끕니다.

**엮음 고르기 명령(새 기능).** 줄을 흘려보내는 단계 목록과 예시 입력을 주면, 단계마다 한 번씩만 재서 더 빠른 순서를 계산합니다. 고른 순서를 한 번 돌려 답이 같은지 확인하고 표로 보여 줍니다. 코드는 바꾸지 않습니다.

**합성 설계 체크리스트.** 계획서에 "순수함수를 어떻게 엮는가"를 묻는 표가 생겼습니다. 표가 없거나 근거 칸이 비면 발표 자료가 경고합니다.

**느린 함수 17개를 고쳤습니다.** 입력이 커지면 크게 느려지던 함수들입니다. 답은 그대로입니다.

**고친 것.** 계획을 보관한 턴이 "진행 중 계획이 없다"로 막히던 것, 저널 폴더를 다른 저장소로 연결해 둔 프로젝트에서 저널이 쌓이지 않던 것을 고쳤습니다.

Core 0.89.0 의 권장 effort 요청은 래퍼가 모델별 권장 표를 실어야 켜집니다. 이 래퍼는 아직 표를 싣지 않아 동작이 그대로입니다.

이 판은 시험과 CI 로만 확인했습니다. 실제 세션에서 돌려 보는 확인은 하지 않았습니다.
