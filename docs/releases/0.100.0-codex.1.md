# 0.100.0-codex.1

Core 0.100.0 을 싣습니다.

**새로 생긴 것 — 기어와 톱니.** 되풀이되는 작업을 프로젝트 `scv/gears/` 안의 재사용 단위로 만듭니다. 톱니는 순수함수처럼 한 가지 일만 하는 아주 작은 sh(`scv/gears/teeth/`), 기어는 맨 위 `flow:` 줄로 톱니를 합성함수처럼 잇는 스킬(`scv/gears/<이름>/GEAR.md`)입니다. 기어를 돌리면 톱니는 스크립트가 직접 돌리고, 판단이 필요한 자리(`@`)에서만 그 기어의 글과 앞 단계 결과를 모델에게 넘깁니다 — 정해진 흐름을 sh 로 내린 만큼 토큰이 줍니다.

**새로 생긴 것 — `$scv:gear`.** 목록 · 만들기 · 검사 · 실행을 합니다. 검사는 순수 톱니를 사전의 예시로 실제로 돌려 맞춰 봅니다.

**알아 둘 것 — 밖으로 나가는 톱니.** push · 네트워크 · 삭제를 하는 톱니는 사용자의 확인이 기록된 뒤에만 도는데, 이 호스트에는 그 확인을 기록하는 길이 아직 없습니다. 그런 톱니 앞에서는 멈추고, 그 단계는 직접 돌려야 한다고 알립니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
