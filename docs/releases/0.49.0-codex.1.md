# 0.49.0-codex.1

Core 0.49.0 동기화. Codex 래퍼 자체의 동작 변경은 없습니다.

## 코어에 들어온 것

- **help 규약은 세션당 한 번.** 규약이 매 턴 라우터(`protocols/help.md`)와 세션당 한 번 읽는
  `protocols/help/full.md` 로 나뉩니다. 다시 읽는 시점은 표식 `scv/journal/.help-state` 로 훅이 정합니다
  (세션 번호 변화 · `SCV_HELP_RELOAD_EVERY`(기본 10)턴마다 · 되찾기 템플릿의 reset). Codex 는 세션 시작
  등가 훅을 등록하지 않으므로, Codex 에서는 세션 번호 변화와 N턴 주기만 작동합니다 — 세션 번호를 주지 않는
  호스트에서는 표식을 건드리지 않고 매 턴 규약 전체를 읽습니다(0.48 동작).
- **진단은 바뀐 턴에만 전체.** `help.sh --with-context` 가 `PROTOCOL: load|loaded` 를 찍습니다.
- 스위치 `SCV_HELP_LOAD_ONCE`(기본 on).
