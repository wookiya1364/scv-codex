# 0.60.0-codex.1

모델이 가이드 원문을 실제로 읽었는지, 다시 쓴 요청을 답에 보였는지를 결과로 확인합니다. Core pin 은 `0.60.0`.

## 무엇이 달라지나

- **원문을 안 읽고 넘어가면 다음 턴에 경고가 뜹니다.** help 가 읽음 표시 명령을 그대로 건네고, 턴이 끝날 때 표시가 없으면 다음 턴
  맨 앞에 경고 한 줄이 실리고 help 가 원문을 다시 읽게 합니다.
- **다시 쓴 요청을 대화 기록에만 남기고 답에 안 보이면 경고가 뜹니다**(답에 인용 블록 `>` 으로). 이 판정은 멈춤 훅이 대화 원본에서
  답 텍스트를 읽을 수 있을 때만 돕니다 — 읽지 못하면 조용히 건너뜁니다.
- 답을 막거나 고치지는 않습니다 — 경고만.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
