# 0.72.1-codex.1

Core 0.72.1 을 싣습니다(0.72.0-codex.1 은 운영에 나가지 않고 이 판으로 합쳤습니다). 병합 전에 개인정보(로컬 경로 · 세션 id · 비밀 목록 낱말)를 막는 검사가 생겼고, 매 턴 훅이 빨라졌습니다.

- 개인정보 검사: PR 의 커밋 메시지와 더해진 줄에서 로컬 경로 · 세션 id · 세션 링크 줄 · 비밀 목록 낱말을 찾으면 막습니다. 이 저장소의 branch-flow 에도 같은 검사 단계가 들어갔습니다.
- 매 턴 훅 속도: 설정을 키마다 따로 읽던 것을 한 번에 읽어, 빈 저장소 기준 매 턴 7.3 → 1.8초, 진단 5.7 → 0.5초.
- 코어 시험 실행 도구 `run-focused.sh`: 실패한 시험의 로그 전문을 찍고, 속도 검사는 끝에 혼자 돕니다.
- 문서: README 3개 언어에 구조 · 루프 그림과 명령 한눈 표.
- 코어 시험 하나(다시 쓴 요청 속도 검사)의 상한을 10초 → 30초로 — 시험을 4개씩 동시에 돌리는 이 저장소 CI 에서 11초가 나와 0.72.0-codex.1 승격이 멈췄습니다. 동작 변화는 없습니다.
