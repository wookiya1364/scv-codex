# 0.64.0-codex.1

SCV 원칙이 단위 표 하나로 바뀌고, 맥 기본 셸에서 종료 훅이 빨라집니다. Core pin 은 `0.64.0`.

## 무엇이 달라지나

- **SCV 원칙은 단위 표 하나로**: 표식은 `[SCV 원칙 적용 — 단위 표]`, 단위 표는 '단위 | 해결책 | 추천' 세 칸 — 해결책이 그 방법이 부를
  문제를 막는 길까지 담고, 문제 표 · '생길 수 있는 문제' 칸은 없습니다(답에 넣으면 종료 훅이 한 번 막습니다).
- **결정 묻기는 지금처럼**: Codex 에는 고르는 선택지 도구가 없어 결정은 예전처럼 번호로 답하는 표로 묻습니다(Core 0.64.0 의 선택지 규칙은
  이 래퍼에서 꺼져 있습니다).
- **맥 기본 셸(bash 3.2)**: 긴 답에서 종료 훅이 1분 넘게 걸리던 것이 1초 안으로 줄었습니다.
- Codex 세션 기록은 줄 모양이 달라 종료 훅이 턴 경계를 넓혀 찾지 않습니다 — 판정은 예전과 같고, 판정 기록에 쌓이던 '경계 없음' 줄이
  없어집니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
