# 0.72.2-codex.1

Core 0.72.2 를 싣습니다. codex 의 deck 동작은 그대로입니다 — 엔진 사본이 원래 하나뿐이었습니다.

- 코어에 래퍼 설정 `SCV_DECKUI_DIR`(deck 엔진 자리)가 생겼습니다. codex 는 코어 사본 안 엔진을 그대로 쓰므로 설정하지 않습니다. claude 래퍼는 이 설정으로 중복 사본을 지웠습니다.
- 고친 버그: deck 생성기가 Graft 어댑터를 못 찾던 문제. Graft 가 준비된 저장소에서는 deck 문서에 변경 지도가 붙습니다(의도된 변화).

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
