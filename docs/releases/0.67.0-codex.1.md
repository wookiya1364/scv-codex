# 0.67.0-codex.1

Core 0.67.0 을 싣습니다. Core pin 은 `0.67.0`.

## 무엇이 달라지나

- **검토 시점에 실제 결과 보여 주기**: 언제 보여 주고 물을지를 정해 두었으면(예: 커밋 뒤 검토) 모델은 그 시점을 앞당기지 않고,
  그때 요약 대신 실제로 돌린 결과(명령 출력 · 함수 호출 결과)를 그대로 보이며 글 질문 한 번으로 묻습니다. 돌려 볼 수 없으면 못 돌린
  이유를 한 줄로 밝히고 묻습니다. 끄기: 설정 `SCV_SHOW_REAL=off`.
- Codex 에는 고르는 선택지 도구도, 사람이 없는 실행을 가리는 조건도 없어 무인 실행에서도 글 질문 문구가 실립니다(알려진 한계).

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
