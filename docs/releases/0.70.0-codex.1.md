# 0.70.0-codex.1

Core 0.70.0 을 싣습니다 — 명령 목록에 모드 명령 셋(`mods` · `mods-install` · `mods-remove`)이 들어왔고, Codex 에서는 '모드 없음'을 한 줄로 알립니다. Core pin 은 `0.70.0`.

## 무엇이 달라지나

- **새 명령 `$scv:mods` · `$scv:mods-install` · `$scv:mods-remove`(17–19번째)**: SCV 모드(scv-mods)는 Claude 데스크톱 앱 플러그인입니다.
  Codex 에서 부르면 아무것도 실행하지 않고 "Codex has no SCV mods" 한 줄로 답합니다.
- Claude 래퍼(0.70.0)에서는 같은 세 명령이 모드를 업데이트 · 설치 · 삭제합니다(인자 없음, 설치 · 삭제는 선택 창).
- `$scv:update` 는 그대로입니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
