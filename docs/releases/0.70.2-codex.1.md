# 0.70.2-codex.1

Core 0.70.2 를 싣습니다. 계획서 양식이 단계마다 '하는 일'을 적고 단계 줄을 파이프라인 표와 잇게 바뀌었습니다. Core pin 은 `0.70.2`.

## 무엇이 달라지나

- 새로 만드는 계획서의 `순수함수 · 파이프라인` 표에 '하는 일' 칸(한 줄, 쉬운 말)이 생깁니다.
- `Suggested path` 줄 끝에 그 줄이 만드는 단계를 `` — `단계`, `단계` `` 로 적습니다(표의 단계 칸과 글자 그대로).
- 이미 쓴 계획서는 그대로 읽힙니다.

## 올리는 법

```
codex plugin marketplace upgrade scv-codex
codex plugin add scv@scv-codex
```
