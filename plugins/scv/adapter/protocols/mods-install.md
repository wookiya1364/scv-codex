# $scv:mods-install

Codex has no SCV mods. SCV mods (for example `scv-hello`, the SCV pane) are
Claude Code desktop-app plugins; the Claude wrapper's mods commands install,
update and remove them there.

## Protocol

When the user asks to install an SCV mod, answer in one line, in the user's language:
Codex has no SCV mods — they run in the Claude desktop app. Run nothing and
change nothing.
