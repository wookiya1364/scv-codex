# SCV compatibility pointer for Codex
<!-- SCV:HOST-POINTER target=SCV.md -->

The canonical, host-neutral SCV workflow index and workspace state live in
[`SCV.md`](./SCV.md). Read and follow that file for SCV work.

This pointer is adapter-owned. Existing projects whose historical SCV state is
still stored in `CODEX.md` remain supported during migration; `$scv:sync`
previews the migration before moving canonical state to `SCV.md`.
